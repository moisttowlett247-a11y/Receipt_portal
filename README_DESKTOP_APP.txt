=============================================================================
  FARM & SMALL BUSINESS RECEIPT PROCESSOR — DESKTOP RUNTIME BUNDLE
=============================================================================

This package contains everything required to launch and run the high-speed
desktop receipt processor with OCR, QuickBooks sync, and live license support.

QUICK START:
-----------------------------------------------------------------------------
1. WINDOWS:
   - Double-click "run_receipt_processor.bat"
   - It verifies Python, installs dependencies automatically, and starts the GUI.

2. MACOS / LINUX:
   - Open Terminal in this folder.
   - Run: chmod +x run_receipt_processor.sh
   - Run: ./run_receipt_processor.sh

REQUIREMENTS:
-----------------------------------------------------------------------------
- Python 3.10+ (Download from https://www.python.org/ — check "Add Python to PATH")
- Internet connection for Gemini Vision OCR and QuickBooks API.

FILES IN THIS BUNDLE:
-----------------------------------------------------------------------------
- receipt_processor.py       : The main application Python script.
- run_receipt_processor.bat  : Windows 1-click batch launcher.
- run_receipt_processor.sh   : macOS / Linux shell launcher.
- requirements.txt           : Python dependency manifest.
- .env.example               : Optional configuration template.
- README_DESKTOP_APP.txt     : This instruction guide.

ACTIVATING YOUR LICENSE:
-----------------------------------------------------------------------------
Click "🔑 Subscription & License Key" in the top-right corner of the app
window to enter your active license key generated from the Admin Portal.
